# Komşu Matkap Sessizlik İhlali Tutanağı

Resmi olmayan resmi daire. Dosya no: **KM-2026-1009**.

Bu yazılım, üst kattan gelen matkabı duyguya göre değil, saate, kata ve süreye göre yargılar. Çalışır. İşe yaramaz. İkisi de kasten.

Patates yoktur. Patates arayan yanlış dairededir. Burası delik açma diplomasisidir.

## Neden var?

Çünkü bir gün birisi cumartesi 09:12'de duvara “iki dübel yeter” dedi ve bina anayasa değişikliği yaşadı. Bu depo o anın tutanağıdır.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Matkap harici bir şey istemez, o da yazılımın içinde değil, komşunun elindedir.

```bash
python3 matkap_tutanak.py --saat 09:12 --kat 4 --sure 18 --gun cumartesi
python3 matkap_tutanak.py --demo
```
